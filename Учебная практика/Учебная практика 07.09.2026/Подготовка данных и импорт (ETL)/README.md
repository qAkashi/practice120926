# Подготовка данных и импорт (ETL)

Исходные и очищенные файлы, карантин, импорт и проверки количества строк и сумм.

- `source/` — предоставленные исходные файлы.
- `cleaned/` — подготовленные CSV. `sales.csv` — вспомогательная сверка, отдельной таблицы sales нет.
- `quarantine/rejected_sales.csv` — отклонённая продажа со ссылкой на отсутствующего партнёра.
- `data.sql` — импорт через обычные INSERT, подходит для Query Tool в pgAdmin.
- `import.sql` — альтернативный импорт через psql и \copy, запускать из этой папки.
- `checks.sql` — SELECT COUNT(*) по таблицам и проверки импортированных сумм.
- `screen/` — скриншоты импорта и сверки.

Выберите один способ импорта: data.sql либо import.sql/мастер CSV. Не выполняйте оба поверх тех же данных.
Порядок CSV: partners, products, deliveries, delivery_items.
После исходного импорта: 3 партнёра, 3 товара, 4 отгрузки, 4 позиции;
объём 430 единиц и сумма 67 000,50. Тестовые записи приложения меняют эти количества.
Цена строки 102 — 90.0025: четыре знака сохраняют исходную сумму 18 000,50.
