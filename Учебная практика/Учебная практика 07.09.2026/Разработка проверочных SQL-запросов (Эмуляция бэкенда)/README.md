# Разработка проверочных SQL-запросов (Эмуляция бэкенда)

Список партнёров с количеством доставок, транзакция добавления и история отгрузок за период.

Откройте `queries.sql` в pgAdmin. Выделяйте и выполняйте отдельные блоки:
список партнёров, транзакцию BEGIN…COMMIT, историю за период.
Параметры партнёра и дат задаются в CTE params.
Тестовая транзакция записывает данные; повторный запуск с тем же ИНН может вызвать UNIQUE.
После такого сбоя выполните ROLLBACK отдельно и используйте другой ИНН/email или существующую карточку.
В `screenshots/` сохранены результаты SQL-запросов.
