# Учебная практика 07.09.2026

В этой директории четыре задания.

1. [Проектирование базы данных (3NF) и ER-диаграмма](<Проектирование базы данных (3NF) и ER-диаграмма/README.md>) — Модель в 3NF: partners, products, deliveries, delivery_items. ER-диаграмма в PDF и исходник pgAdmin.
2. [Написание DDL-скрипта (База данных в коде)](<Написание DDL-скрипта (База данных в коде)/README.md>) — Исходная схема PostgreSQL: PK, FK, NOT NULL, UNIQUE, CHECK, типы данных и порядок DROP/CREATE.
3. [Подготовка данных и импорт (ETL)](<Подготовка данных и импорт (ETL)/README.md>) — Исходные и очищенные файлы, карантин, импорт и проверки количества строк и сумм.
4. [Разработка проверочных SQL-запросов (Эмуляция бэкенда)](<Разработка проверочных SQL-запросов (Эмуляция бэкенда)/README.md>) — Список партнёров с количеством доставок, транзакция добавления и история отгрузок за период.

Это блок SQL и проектирования; запуск Python здесь не нужен. SQL открывается через Query Tool в pgAdmin.
Для новой пустой БД выполните schema.sql из задания 2, затем data.sql и checks.sql из задания 3.
Для существующей БД не запускайте schema.sql повторно: он удаляет таблицы.
