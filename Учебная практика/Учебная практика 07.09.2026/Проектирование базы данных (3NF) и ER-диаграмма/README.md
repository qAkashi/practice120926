# Проектирование базы данных (3NF) и ER-диаграмма

Модель в 3NF: partners, products, deliveries, delivery_items. ER-диаграмма в PDF и исходник pgAdmin.

Файлы: `er_diagram.pdf`, `diagramm.pgerd`, `full.jpg`.

Партнёр имеет много отгрузок, отгрузка — много позиций, товар встречается в разных позициях.
Данные партнёра хранятся только в partners, название товара — только в products.
Дата и партнёр определяются delivery_id; количество и цена относятся к позиции
с составным ключом (delivery_id, line_number). Итоги рассчитываются запросом.
Цена в позиции фиксирует цену сделки, а не текущий прайс товара.
Имена таблиц во множественном числе, поля — snake_case.
Схема этого этапа не включает новые поля карточки, добавленные миграцией 21.09.
