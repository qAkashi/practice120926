# Написание DDL-скрипта (База данных в коде)

Исходная схема PostgreSQL: PK, FK, NOT NULL, UNIQUE, CHECK, типы данных и порядок DROP/CREATE.

`schema.sql` создаёт четыре таблицы и ограничения. `schema_created.jpg` — результат в pgAdmin.
Для первой установки: выберите пустую базу в pgAdmin, откройте Query Tool,
загрузите schema.sql значком папки и выполните F5.
Скрипт содержит DROP TABLE, поэтому не предназначен для обновления заполненной БД.
