# Наполнение интерфейса, отладка и стресс-тестирование

Версия приложения со списком из БД, обработкой отсутствия продаж и ошибок соединения, тестами.

Здесь сохранена рабочая версия этапа 14.09: загрузка списка из PostgreSQL,
контакты, поиск, скидки, обработка NULL/нулевых продаж и ошибок соединения.
Запуск: `main.py` в этой папке или `run_app.py` уровнем выше.
Тесты: `run_final_tests.py`; снимки интерфейса — `screenshots/`.
Следующий блок 21.09 развивает это приложение и добавляет CRUD.
