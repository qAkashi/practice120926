# Разработка интерфейса (UI) по руководству по стилю

Первый экран Tkinter: логотип, иконка, шрифты и карточки. Есть preview.py без подключения к БД.

`app.py` — первое окно списка; `theme.py` — оформление; `presentation.py` — форматирование.
`resources/` содержит логотип и иконку. Для просмотра макета без БД запустите `preview.py`.
`main.py` запускает эту версию с подключением к PostgreSQL; настройки рядом в `database.ini`.
Это интерфейс этапа 14.09, ещё без окна редактирования.
