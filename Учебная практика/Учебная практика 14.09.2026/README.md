# Учебная практика 14.09.2026

В этой директории четыре задания.

1. [Разработка ядра бизнес-логики (Расчет скидки)](<Разработка ядра бизнес-логики (Расчет скидки)/README.md>) — Изолированный расчёт скидки и проверки порогов 9 999, 10 000, 49 999, 50 000 и 300 000.
2. [Интеграция с БД и агрегация данных (SQL + Backend)](<Интеграция с БД и агрегация данных (SQL + Backend)/README.md>) — Подключение Psycopg, SUM(quantity), LEFT JOIN и данные партнёра с вычисленной скидкой.
3. [Разработка интерфейса (UI) по руководству по стилю](<Разработка интерфейса (UI) по руководству по стилю/README.md>) — Первый экран Tkinter: логотип, иконка, шрифты и карточки. Есть preview.py без подключения к БД.
4. [Наполнение интерфейса, отладка и стресс-тестирование](<Наполнение интерфейса, отладка и стресс-тестирование/README.md>) — Версия приложения со списком из БД, обработкой отсутствия продаж и ошибок соединения, тестами.

Для версии этого этапа запустите run_app.py из этой директории. Полные тесты этапа — run_tests.py.
Это сохранённая версия со списком партнёров. Добавление и редактирование реализованы в следующем блоке, 21.09.2026.
