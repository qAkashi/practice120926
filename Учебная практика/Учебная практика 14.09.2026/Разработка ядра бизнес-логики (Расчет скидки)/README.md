# Разработка ядра бизнес-логики (Расчет скидки)

Изолированный расчёт скидки и проверки порогов 9 999, 10 000, 49 999, 50 000 и 300 000.

`partner_discount.py` содержит calculate_partner_discount(total_quantity).
Пороги: < 10 000 — 0%; < 50 000 — 5%; < 300 000 — 10%; иначе 15%.
В VS Code запустите `manual_check.py` для ручных значений или `run_tests.py`
для pytest и проверки 100% покрытия функции.
