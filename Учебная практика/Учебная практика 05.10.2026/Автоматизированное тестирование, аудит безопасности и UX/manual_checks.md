# Ручная проверка перед сдачей

1. Запустите run_app.py текущей папки, подключитесь к practice_051026.
   Проверьте список, логотип и заголовок.
2. Нажмите «Добавить партнёра» и «Сохранить» с пустой формой.
   Ожидается Error с шагами исправления. Карточка остаётся открытой.
3. Проверьте рейтинг: минус, буквы и дробная часть не вводятся.
   Пустой рейтинг при сохранении вызывает Error.
4. Введите неверный Email, затем уже существующий ИНН.
   Ожидается ошибка; поля не очищаются, новая запись не создаётся.
5. Измените поле и нажмите «Назад». Ожидается Warning о потере данных.
   Нажмите «Нет»: черновик остаётся. Затем «Назад» → «Да»: окно закрывается.
6. Сохраните корректного нового партнёра с уникальными ИНН и Email.
   Ожидается Information об успехе и автоматическое обновление списка.
7. Отредактируйте существующего партнёра. Проверьте, что история продаж сохранилась.
8. В поиске введите ' OR 1=1; --. Это обычный текст поиска:
   ошибка SQL не появляется, данные остаются целыми.
9. Для безопасной проверки недоступности БД закройте приложение, временно
   укажите неиспользуемый порт в database.ini третьей папки, запустите приложение.
   Ожидается Error с тремя шагами восстановления. Верните правильный порт и
   нажмите «Подключиться». Рабочую службу PostgreSQL останавливать не требуется.
10. Во время загрузки многократно нажмите «Обновить» или открытие карточки.
    Ожидается один запрос/одно окно. Закрытие приложения во время чтения допустимо.
11. Запустите run_tests.py. Для подтверждения полного прогона с БД задайте
    TEST_DATABASE_DSN; без него интеграционные проверки явно помечены skipped.

Для отчёта можно сохранить скриншоты Error, Warning и успешного сохранения.
Используйте только реальные результаты своего запуска.
