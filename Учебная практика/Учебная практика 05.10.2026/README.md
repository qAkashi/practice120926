# Учебная практика 05.10.2026

Первое задание: [Инфраструктура данных и ETL (База данных в 3NF)](<Инфраструктура данных и ETL (База данных в 3NF)/README.md>).

Создана отдельная схема PostgreSQL для новых файлов партнёров, товаров и продаж.
Подготовлены исходные и очищенные CSV, ETL на Python, DDL, импорт и проверки.
Результат очистки — 5 партнёров, 3 товара и 5 продаж; битая ссылка исключена из загрузки.

Для импорта в свою PostgreSQL откройте run_import.py внутри задания и нажмите Run Python File
в VS Code, затем введите пароль. В README задания также описан вариант через pgAdmin.
Новая база называется practice_051026; предыдущая CRM продолжает использовать partner_shipments.

Второе задание: [Реализация ядра бизнес-логики (Расчеты и алгоритмы)](<Реализация ядра бизнес-логики (Расчеты и алгоритмы)/README.md>).

Реализованы скидки по объёму продаж из sales_history и расчёт сырья с чтением
коэффициента и процента брака из справочников PostgreSQL. Для демонстрации запустите
run_demo.py во второй папке, для проверки — run_tests.py там же.
Учебные справочники создаются при первом запуске демонстрации.

Третье задание: [Разработка UI, навигации и CRUD-форм](<Разработка UI, навигации и CRUD-форм/README.md>).

Главный экран, карточка добавления/редактирования и история продаж работают
с practice_051026. Запуск — run_app.py внутри третьей папки. Дополнительные поля
партнёра создаются автоматически, скидки берутся из бизнес-логики второго задания.
После сохранения список обновляется; поиск, выбор и прокрутка сохраняются.

Четвёртое задание: [Автоматизированное тестирование, аудит безопасности и UX](<Автоматизированное тестирование, аудит безопасности и UX/README.md>).

Блок завершён: четыре папки заданий. Итоговый интерфейс запускается через run_app.py
четвёртого задания, общий прогон всех четырёх наборов — через run_tests.py там же.
Пройдены 174 теста, включая PostgreSQL, устойчивость окон и SQL-инъекции.
Отчёт аудита — security_audit.md в четвёртой папке.
