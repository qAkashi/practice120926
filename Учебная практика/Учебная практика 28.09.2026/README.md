## Запуск в VS Code

1. Откройте всю папку `hexlet`.
2. Выберите интерпретатор `.venv/Scripts/python.exe` через **Python: Select Interpreter**.
3. Откройте `run_app.py` в корне репозитория и нажмите **Run Python File**.
4. Введите пароль PostgreSQL, который используете в pgAdmin.
5. Выберите партнёра одним щелчком и нажмите **История продаж**.
6. Для расчёта материалов нажмите **Расчёт сырья** на главной форме.
   Введите ID продукции 1, ID материала 1, количество 10 и параметры 2 и 3.
   Нажмите **Рассчитать**: результат — 95.

Калькулятор работает без PostgreSQL. Если нужно проверить только его, отмените первоначальное
окно подключения и нажмите «Расчёт сырья» в реестре. Неизвестный ID или отрицательный размер
вызовет диалог ошибки; исправьте поле и повторите расчёт.

Также можно запускать run_app.py из этой папки с выбранным интерпретатором проекта.
Настройка окружения и создание базы описаны в [общем README](../../README.md).

## Связь с предыдущими заданиями

`project_paths.py` подключает общие модули версии 21.09: работу с PostgreSQL, расчёт скидки,
форму редактирования, уведомления, шрифты, цвета, логотип и иконку.
История расширяет MainWindow через наследование; версия 21.09 продолжает запускаться отдельно.
При скачивании с GitHub нужна вся папка репозитория, включая предыдущие блоки.

Используется [database.ini из блока 21.09](<../Учебная практика 21.09.2026/Интеграция формы с БД (CRUD-операции и обновление UI)/database.ini>).
Если предыдущая версия уже работала, для истории менять схему БД не требуется.

Расчёт сырья использует учебные мок-справочники, разрешённые заданием. Для него не требуется
подключение к БД. Откройте manual_check.py в папке «Разработка ядра алгоритма расчета материалов» и нажмите
Run Python File: скрипт запросит пять входных значений и покажет целый результат либо -1.

## Проверка

Запустите корневой `run_tests.py`. Тесты используют отдельные схемы и временные таблицы;
рабочие данные не меняются. Пользователю тестового подключения требуется право CREATE на БД.
Общий результат находится в [test_results.txt](test_results.txt).
Для отдельной проверки расчёта сырья без PostgreSQL запустите run_tests.py из папки второго задания.
Для проверки его интерфейса без PostgreSQL запустите run_ui_tests.py из папки третьего задания.
