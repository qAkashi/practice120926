# Расчёт потребности в сырье

Второе задание блока 28.09.2026. Функция `calculate_material_quantity` находится
в [material_calculator.py](material_calculator.py) и принимает ровно пять аргументов:

```python
calculate_material_quantity(product_type_id, material_type_id, quantity, param_1, param_2)
```

ID типов и количество — положительные целые числа. Параметры изделия — положительные
конечные числа. Возвращается целое количество сырья или `-1` при неверных данных.

## Формула из задания

1. Расход на единицу = param_1 × param_2 × коэффициент типа продукции.
2. Чистый расход = расход на единицу × quantity.
3. Расход с браком = чистый расход × (1 + процент брака / 100).
4. Округление результата вверх до целого с помощью ceil.

Промежуточные значения не округляются. Для вычислений используются точные дроби Fraction,
созданные из десятичных представлений чисел. Например, 0.07 × 100 даст ровно 7,
без лишней единицы после округления из-за погрешности двоичного float.

При неизвестных ID, quantity ≤ 0, param_1 ≤ 0 или param_2 ≤ 0 результат равен `-1`.
Также отклоняются строки вместо чисел, bool, NaN, бесконечность и некорректные значения справочников.

## Справочники

Задание разрешает мок-объекты. В исходной БД нет справочников типов продукции и материалов,
поэтому [material_reference_data.py](material_reference_data.py) содержит **учебные значения**.
Они служат для проверки алгоритма и не являются коэффициентами реального производства.
ID типов не связаны с product_id из существующей таблицы products.

| ID типа продукции | Коэффициент |
| --- | --- |
| 1 | 1.5 |
| 2 | 2.0 |
| 3 | 1.0 |

| ID типа материала | Процент брака |
| --- | --- |
| 1 | 5% |
| 2 | 10% |
| 3 | 0% |

Процент хранится числом 5 для 5%, а не 0.05. Коэффициент должен быть больше нуля,
процент брака — от 0 до 100 включительно. При 100% формула задания удваивает расход.
Функция обращается к обоим справочникам при каждом корректном вызове.
При подключении настоящих справочников можно заменить две функции чтения в этом модуле,
сохранив интерфейс расчёта с пятью параметрами.

## Проверка вручную в VS Code

1. Откройте папку hexlet, выберите интерпретатор проекта через Python: Select Interpreter.
2. Откройте [manual_check.py](manual_check.py) из этой папки.
3. Нажмите Run Python File и вводите значения в терминале VS Code.
4. Для примера введите по очереди `1`, `1`, `10`, `2`, `3`.
   Должно появиться «Необходимое количество сырья: 95»:
   2 × 3 × 1.5 × 10 × 1.05 = 94.5 → 95.
5. Запустите ещё раз и введите количество 0 либо неизвестный ID 999: получите `-1`.

Параметры изделия в мини-скрипте можно вводить с точкой или запятой.
Подключение к PostgreSQL для этого задания не требуется.
Метод доступен для вызова из модулей приложения после настройки импортов через project_paths.py.
В третьем задании добавлено [окно калькулятора](<../Интеграция метода расчета и комплексное тестирование/README.md>):
запустите приложение и нажмите «Расчёт сырья».
