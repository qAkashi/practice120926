# Интеграция формы с БД (CRUD-операции и обновление UI)

Загрузка актуальной записи, INSERT/UPDATE, транзакции, сохранение связей с отгрузками и SQL-миграция.

- `database.ini` — сервер, порт, имя БД и пользователь; пароль вводится в окне приложения.
- `database.py` — подключение Psycopg 3.
- `partner_repository.py` — соединение, чтение карточки и подтверждение COMMIT.
- `partner_service.py` — SQL чтения, INSERT и UPDATE с параметрами.
- `partner_discount.py` — используемая приложением функция скидки.
- `migrate_partner_card.sql` — обновление существующей БД без удаления партнёров и отгрузок.
- `schema.sql` — полная итоговая схема для новой пустой БД и изолированных тестов; содержит DROP TABLE.

В pgAdmin выберите partner_shipments, откройте Query Tool и выполните целиком
migrate_partner_card.sql. Если миграция уже выполнена, перенос папок не требует новой миграции.
Для существующей БД не запускайте schema.sql.

Создание получает ID из identity, редактирование сохраняет прежний PK и не меняет отгрузки.
Ошибки откатывают транзакцию. UNIQUE защищает ИНН/email, FK — связи между таблицами.
Карточка читается заново по ID при каждом открытии; после записи список автоматически обновляется.
