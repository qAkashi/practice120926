# Разработка формы добавления и редактирования партнера

PartnerEditWindow: поля карточки, ComboBox, подсказки телефона/email и кнопки действий.

`partner_edit_window.py` реализует два режима карточки. Поля: наименование,
тип из ComboBox, рейтинг, адрес, директор, телефон, email и ИНН для существующей схемы БД.
`tooltip.py` показывает ожидаемый формат телефона и email.
При сохранении форма передаёт данные сервису, при выходе проверяет несохранённые изменения.
Старый дробный рейтинг не округляется: он показан в подсказке, а для записи требуется целое число.
Запуск — через общий run_app.py. Скриншоты формы лежат в screenshots/.
