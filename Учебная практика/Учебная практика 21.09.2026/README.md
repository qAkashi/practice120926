# Учебная практика 21.09.2026

В этой директории четыре задания.

1. [Проектирование многооконной архитектуры и навигации](<Проектирование многооконной архитектуры и навигации/README.md>) — MainWindow, переходы между окнами, сохранение состояния списка, оформление и ресурсы.
2. [Разработка формы добавления и редактирования партнера](<Разработка формы добавления и редактирования партнера/README.md>) — PartnerEditWindow: поля карточки, ComboBox, подсказки телефона/email и кнопки действий.
3. [Интеграция формы с БД (CRUD-операции и обновление UI)](<Интеграция формы с БД (CRUD-операции и обновление UI)/README.md>) — Загрузка актуальной записи, INSERT/UPDATE, транзакции, сохранение связей с отгрузками и SQL-миграция.
4. [Обработка исключений и интерактивные уведомления (UX и UI)](<Обработка исключений и интерактивные уведомления (UX и UI)/README.md>) — Валидация, системные Error/Warning/Information, подтверждение выхода и полный набор тестов.

Четыре папки составляют одно итоговое приложение. Запускайте run_app.py рядом с этим README или в корне репозитория.
project_paths.py связывает модули учебных папок. Для всех тестов запустите run_tests.py.

Настройки PostgreSQL: [database.ini](<Интеграция формы с БД (CRUD-операции и обновление UI)/database.ini>). Обновление существующей БД: [migrate_partner_card.sql](<Интеграция формы с БД (CRUD-операции и обновление UI)/migrate_partner_card.sql>).
