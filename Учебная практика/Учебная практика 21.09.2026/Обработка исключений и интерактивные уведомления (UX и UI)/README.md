# Обработка исключений и интерактивные уведомления (UX и UI)

Валидация, системные Error/Warning/Information, подтверждение выхода и полный набор тестов.

`partner_validation.py` проверяет обязательные поля, целый неотрицательный рейтинг,
формат email/телефона и ИНН. `errors.py` переводит ошибки БД в инструкции для пользователя.
`dialogs.py` показывает системные Error, Warning и Information с нужными пиктограммами.

Ручная проверка через итоговое приложение:

1. Оставьте наименование/email пустыми и нажмите «Сохранить»: ошибка, записи в БД нет.
2. Попробуйте рейтинг -1 или 4.8: ошибка объясняет, как исправить значение.
3. Измените поле и нажмите «Назад»: «Нет» оставляет данные, «Да» отменяет изменения.
4. Сохраните корректную новую запись: появится «Партнёр добавлен».
5. Отредактируйте запись: появится «Изменения сохранены»; ID и отгрузки останутся прежними.
6. При недоступной БД сообщение объясняет проверку службы и настроек подключения.

Все 114 тестов итогового приложения находятся в `tests/`, включая проверки
навигации, формы, CRUD и скидок. Запуск — общий run_tests.py в корне репозитория
или run_final_tests.py здесь. Для БД нужен PostgreSQL: тесты используют временные таблицы
и отдельные схемы со случайным именем, которые удаляются после проверки.
Тестовому пользователю требуется CREATE на БД. Пароль запрашивается скрыто.
Для автоматического запуска можно задать TEST_DATABASE_DSN.
Покрытие partner_discount.py и partner_service.py — 100%, включая ветвления;
это не покрытие всего интерфейса. Результат полного запуска — test_results.txt.
Скриншоты 12–14 показывают три системных диалога.
