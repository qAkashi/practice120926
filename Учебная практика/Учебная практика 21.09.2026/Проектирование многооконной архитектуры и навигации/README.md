# Проектирование многооконной архитектуры и навигации

MainWindow, переходы между окнами, сохранение состояния списка, оформление и ресурсы.

`main.py` создаёт приложение, `main_window.py` отвечает за список, навигацию,
фоновые запросы и автоматическое обновление после сохранения.
`theme.py`, `presentation.py` и `resources/` задают единое оформление.
`app.py` сохраняет совместимость прежнего имени класса.
Запускайте общий `run_app.py` в корне репозитория, чтобы подключились все четыре задания.
